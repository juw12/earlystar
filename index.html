GitHub token (optional)

Without a token, GitHub allows 10 searches/minute and 60 API calls/hour. A token with no scopes (read-only public data) raises this to 30 searches/minute and 5,000 calls/hour. It is stored only in this browser's localStorage.

New call

Creating a call costs 50 points (anti-spam). Opening odds come from EarlyStar's momentum model — then the market takes over.

Sign in (local dev mode)

This server runs with --dev-login: pick any GitHub-style username. On a real deployment this signs in with GitHub.
